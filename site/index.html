dissolve

dissolve turns any React Native view into dust when it leaves. It snapshots the view, splits it into thousands of grains and animates them on the UI thread with Skia. Use it for the moments where something is gone for good: a deleted message, a cleared notification, a completed task.

Five presets, a two line API, haptics included, and nothing runs until the first dissolve.

Installation

Install with Expo, or give the prompt below to your coding agent.

$ npx expo install dissolve-ui @shopify/react-native-skia

Requires Reanimated 4 and react-native-worklets. Works in Expo Go and dev builds, iOS and Android.

Quick start

Wrap your app once, then grab a ref and call dissolve() when an item should go.

MessageRow.tsx
import { useDissolve } from 'dissolve-ui'

function MessageRow({ message, onDelete }) {
  const { ref, dissolving, dissolve } = useDissolve()

  return (
    <Pressable onLongPress={async () => {
      await dissolve({ preset: 'ember' })
      onDelete(message.id)
    }}>
      <View ref={ref} style={{ opacity: dissolving ? 0 : 1 }}>
        <Text>{message.text}</Text>
      </View>
    </Pressable>
  )
}
app/_layout.tsx
import { DissolveProvider } from 'dissolve-ui'

export default function Layout() {
  return (
    <DissolveProvider>
      <Stack />
    </DissolveProvider>
  )
}

dissolve() resolves once the grains have cleared the space, so removing the item right after lets the list close up behind the dust.

Best practices

        
Dust is loud. Save it for endings people chose: deleting, unsending, completing. Do not dissolve on every list update or on navigation, the effect stops meaning anything.

        
Keep one dissolve on screen at a time when you can. Each grain is a sprite, and a full screen view at 2 pt grain is a lot of them.

        
Pair it with an undo. reset() brings the view back, so a toast with “Undo” costs nothing.

        
Reduce Motion is respected: the view simply disappears, with no particles.

Add dissolve-ui to my Expo app.

1. Install it: npx expo install dissolve-ui @shopify/react-native-skia
2. Wrap the root layout in <DissolveProvider>.
3. For each destructive action (delete, unsend, complete), use useDissolve() in the row component:
   attach ref to the row view, hide it with opacity when dissolving is true,
   then await dissolve({ preset }) before removing the item from state.

Use 'dust' for notifications, 'ember' for messages, 'pixel' for media, 'sand' for tasks.
