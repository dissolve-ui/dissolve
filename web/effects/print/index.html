Print

Print is one of the 16 effects of dissolve, an animation library for React Native. The view is printed in, line by line. It runs with useAppear from dissolve-ui.

Usage

Options

OptionTypeDefaultDescription
presetVariantName'gather'Set it to 'print'. Any exit preset also works as an entrance.
grainnumber3Grain size in points. Raised automatically past about 6000 grains per burst.
durationnumber1200Full effect length in ms. Entrances default to 1200.
origin'left' | 'right' | 'top' | 'bottom' | 'center' | { x, y }noneWhere the view starts to assemble. Without it the variant uses its own order.
delaynumber0Wait before starting, in ms. Use index * 40 to stagger a list.
playbooleantrueDissolveIn only. Plays on mount; flip it from false to true to play later.
onAppear() => voidnoneDissolveIn only. Called once the real view is visible.
hapticsbooleanfalseEntrances are quiet by default, lists can stagger many of them.
field'cascade'noneReplaces the native delay with a diagonal wave, for lists and full screens.

Best practices

  • Made for documents that are produced: receipts, tickets, invoices, generated reports.
  • Tall views read best, the head prints line by line from the top.
  • Avoid it on short pills or chips, there are too few lines to see the print.
  • Fresh ink starts with a cool tint and settles to the real colors, so it works on light and dark themes.
  • With reduced motion the view simply appears.

Install

Install the package and its peers, then wrap the app once in <DissolveProvider>, above the navigator.
